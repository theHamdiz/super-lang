Testing

test "name" { ... } blocks live beside implementation and run with super test. Stripped from super build --release.

test "parses a port" {
  port = parse_port("8080")
  #assert(port > 0)
  assert_eq(port, 8080)
  #assert_err(parse_port(""), "empty port")
}

#assert(expr) evaluates captured operands once and includes their values in a failure. Use assert_eq(actual, expected) when equality is the intent. #assert_err(expr) requires an error; its optional second argument requires the exact error text.
