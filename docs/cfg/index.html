Quickstart

Conditional compilation and Pod features

Super 0.1.0 evaluates #cfg(...) on complete items before imports, macros, type checking, laws/proofs, and code generation.

#cfg(target_os = "linux")
use std.sys.io_uring

#cfg(all(unix, feature = "tls"))
+serve() => start_tls()

#cfg(not(feature = "tls"))
+serve() => fail "TLS feature disabled"

Predicates

all(...), any(...), not(...), unix, windows, debug_assertions, test, and value predicates for target_os, target_arch, target_env, target_family, and feature.

Pod features

[features]
default = ["tls"]
tls = []
full-io = ["tls"]

Build with --features tls,full-io, --all-features, or --no-default-features. Unknown features and malformed predicates fail the build. Disabled imports and law/proof items are removed before macro execution.
