Install Super

One command installs the 0.1.0 toolchain into ~/.super — outside ~/.cargo — with CLI, stdlib, LSP, and MCP shims.

One-liner

From any shell with curl (or FreeBSD fetch):

sh -c 'f=$(mktemp) && trap "rm -f -- \"$f\"" 0 && curl --proto =https -fL https://thehamdiz.github.io/super-lang/install.sh -o "$f" && sh "$f" "$@"' sh

Prefers a GitHub release bundle for your OS/CPU; otherwise clones and builds with a stable Rust toolchain. Open a new shell after PATH is updated.

Where files land

~/.super/
  bin/super
  bin/super-lsp      # → super lsp
  bin/super-mcp      # → super mcp
  lib/stdlib/        # use std.*
  registry/          # super publish / version deps
  cache/             # git Pods

Override with SUPER_HOME, or set SUPER_USE_XDG=1 for $XDG_DATA_HOME/super. Runtime still honors SUPER_STD / SUPER_STDLIB.

From a checkout

git clone https://github.com/theHamdiz/super-lang.git
cd super-lang
./scripts/install.sh
# or: make install

super --help
super check examples/01_space_shooter/src/main.sr
super test  examples/01_space_shooter/
super run   examples/01_space_shooter/src/main.sr
