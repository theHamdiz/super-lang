Super for APIs and ECS

Super (.sr) is a stack-oriented language with low-boilerplate expression syntax, scoped data stacks, heavy comptime, C23 AOT, a bytecode VM, and a numeric-loop JIT — plus optional law/proof files beside ordinary tests. One tree feeds SuperAot and SuperJit for backends and data-oriented engines.

  • Expression syntax without fn / let ceremony
  • Frame-local allocation via scoped data stacks (Memory axis leader)
  • super verify for law/proof sidecars (experimental checker)

Install in one line

sh -c 'f=$(mktemp) && trap "rm -f -- \"$f\"" 0 && curl --proto =https -fL https://thehamdiz.github.io/super-lang/install.sh -o "$f" && sh "$f" "$@"' sh

Syntax without ceremony

+TaxRate = 0.14

+User = {
  id: i64
  name: str
  balance: f64 = 0.0

  discount(@self, percent: f64) : f64 {
    cut = self.balance * (percent / 100.0)
    self.balance -= cut
    self.balance
  }
}

+add_tax(amount: f64) => amount * (1.0 + TaxRate)

final = @u.discount(10.0).add_tax().round(2)
