Quickstart

Build an HTTP server

Route handlers have the static type Fn[http.Request, http.Response]. A route with the wrong arity or return type is rejected before the server starts.

use std.net.http

app = #routes {
  get "/health" {
    http.ok({status: "ok"})
  }
}

@app.serve("127.0.0.1:8080")

#routes { ... } builds an App through typed calls and rejects duplicate method/path pairs. The clean route methods are get, post, put, patch, and delete.

App.serve(address) is the normal serving path. It installs graceful signal handling and uses the default server limits. Use serve_with(address, ServeConfig) to override limits. Applications that need direct lifecycle control may use http.Server and sys.signal.Notify.

This path is not allocation-free yet. Measured on the C23 AOT build, the hello server makes 256 heap allocations per request and frees 7 of them, so memory grows with the number of requests served. A test pins these counts. Request-scoped reclamation is not implemented; see the 0.1.0 changelog.

Windows C23 AOT sockets: Winsock2 (WSAPoll) in 0.1.0. Treat production HTTP on Windows as Rust-hosted VM only until native Windows AOT socket CI is green.
