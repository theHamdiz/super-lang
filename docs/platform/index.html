Platform support

Super 0.1.0 assigns Tier 1 to platforms with native CI host tests, Pod feature configurations, and a C23 hello-world. Tier 2 receives compile and native smoke coverage without the full production networking or release-runner guarantees. On Windows, Tier 1 covers the CLI, VM, and C23 console smoke only — Windows C23 AOT sockets: Winsock2 (WSAPoll) in 0.1.0.

install.sh supports Linux, macOS, and FreeBSD. Windows PowerShell 5.1 and 7+ use install.ps1. Both require SHA256 verification and abort on corrupt input.

Generated C23 avoids Linux-only headers on other targets. Windows C23 AOT sockets: Winsock2 (WSAPoll) in 0.1.0. C23 AOT binaries link Winsock2 (-lws2_32) and use WSAPoll for readiness. TLS/QUIC on Windows remain out of scope for 0.1.0.

WASI uses super build --target wasm32-wasi and is not an installer bundle.
