Quickstart

Data stacks

Super allocates transient data on scoped bump stacks (lexical frame, HTTP request, game frame). Destination-driven APIs write through caller-provided buffers where possible, reducing allocator traffic — this is the primary driver of the published Memory axis result for SuperAot.

super run examples/doc_data_stack/main.sr

Limits and known gaps

Non-@ reference escape rules are specified in SPECIFICATION.md §lifetimes; full diagnostic coverage is still expanding in 0.1.0.
