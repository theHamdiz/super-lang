Pod features

Pod manifests declare a closed feature set. Defaults are enabled unless --no-default-features is present, and feature dependencies are expanded transitively before #cfg(feature = "...") is evaluated.

[features]
default = ["tls"]
tls = []
full-io = ["tls"]
super check --features tls,full-io src/main.sr
super test --all-features .
super build --no-default-features src/main.sr

--features, --all-features, and --no-default-features are accepted by feature-aware build, check, run, and test commands. Unknown feature names, dependency cycles, and malformed declarations fail before compilation.

Use #cfg(feature = "tls") on complete items. Disabled items are stripped before imports, macro expansion, semantic analysis, laws/proofs, and code generation.
