Quickstart

Language reference (0.1.0)

+ before a definition means exported. Every top-level definition without + is private to its module.

Keywords are the only bare syntax. Every compile-time, user-extensible construct is a #-prefixed macro, such as #assert(…) or #routes { … }; everything else is a function or a method.

  • Declarations — bindings use name =; exported definitions use +name =. There is no fn or let.
  • @receiver — in-place mutation calls (SPEC §D).
  • UFCS — value.method(args) (SPEC §D).
  • it / index — implicit in for / when / pipelines.
  • ? ! or — optionals, value errors, recovery (SPEC §F).
