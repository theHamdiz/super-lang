Quickstart

Comptime

Constants, table literals, and compile-time branches are evaluated before AOT C23 emission or VM bytecode load. Restrictions: no I/O, no host calls in pure comptime tables unless explicitly allowed by the module.

+TABLE = [0, 1, 4, 9, 16]

+square(n: i64) : i64 {
  if n < 0 { return 0 }
  if n >= len(TABLE) { return n * n }
  TABLE[n]
}

Run: super check examples/doc_comptime/main.sr
