Macros and Pods

Macros ship as Super source (no opaque binary plugins). Pods are tar+zstd archives with a pod.manifest first entry — see SPECIFICATION.md §Pod.

// examples/doc_pod/
super check examples/doc_pod/main.sr
super pod verify examples/doc_pod
