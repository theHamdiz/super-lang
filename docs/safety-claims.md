<h2 id="explicit-non-claims">Explicit non-claims</h2>
<ul><li>Law/proof discharge is <strong>not</strong> a theorem prover; many <code>.law.sr</code> files remain sidecar models (<code>docs/LAWS_STATUS.md</code>).</li><li>Self-rolled TLS remains experimental (<code>docs/reports/C6-tls-verification.md</code>).</li><li>Memory axis leadership does <strong>not</strong> imply zero allocation on all server paths.</li><li>Benchmark composite <strong>89.2</strong> is one machine snapshot — not a universal speed ranking.</li><li>VM <code>sys_req_*</code> reclaim is <strong>not</strong> implemented (AOT only for long-running servers).</li><li>Epoll / io_uring / TLS / QUIC on Windows AOT are <strong>unsupported</strong>.</li></ul>
