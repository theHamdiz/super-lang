Why these weights

Each axis guards against a different failure mode.

What is the timing protocol?

Versioned protocol (see Protocol version in the suite report): discard 1–2 warm-up runs per language, then N timed runs (default 10) interleaved round-robin across languages. Primary wall is the median (or trimmed mean). Every figure ships with stdev and a CI; overlapping CIs are within noise — not a hard ranking.

What is Cycle?

Compile wall (zero for interpreters and SuperJit) plus the first checksummed verify run. It approximates an agent edit→test loop.

What is Reliability?

Share of gated algorithms that finish with a matching CHECKSUM. Incomplete ports cannot hide behind a selective geo-mean.

How does ratio-to-best work?

For lower-is-better metrics, score = 100 × best / value. For Reliability, score = 100 × rate / best rate. Floor is 0.01.

How do failures affect Speed?

A checksum or compile failure injects 2× the slowest successful primary wall on that algorithm (or the suite timeout) into the geo-mean.

What does LoC measure?

Non-blank, non-comment source lines for the primary file of each language. SuperAot and SuperJit share algo.sr.
