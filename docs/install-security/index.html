Quickstart

Installer security

  1. Download and read first: curl -fsSL https://thehamdiz.github.io/super-lang/install.sh -o install.sh && less install.sh
  2. Release SHA256: verify SHA256SUMS on GitHub release v0.1.0 (see release assets).
  3. Manual path: download super-0.1.0-*.tar.gz, extract bin/super and stdlib/ under ~/.super/.
  4. Installer touches: ~/.super/bin, ~/.super/lib/stdlib, optional registry/cache dirs — never ~/.cargo.
