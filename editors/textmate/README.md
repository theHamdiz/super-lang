# Super TextMate bundle

Drop-in bundle for TextMate 2 / compatible editors:

```bash
# Symlink (macOS TextMate)
ln -sfn "$(pwd)/Super.tmbundle" ~/Library/Application\ Support/TextMate/Bundles/Super.tmbundle

# Linux (manual)
cp -a Super.tmbundle ~/.local/share/textmate/Bundles/
```

Contents mirror `editors/vscode/syntaxes/super.tmLanguage.json` (scope `source.sr`, extension `.sr`).
